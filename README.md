# Портфолио аналитика данных — Айнур Аймурзиева

Проекты по продуктовой аналитике, A/B-тестированию и исследовательскому анализу данных. Каждая папка содержит Jupyter-ноутбук с кодом, графиками и выводами, а также README с кратким описанием.

| # | Проект | Задача | Методы и инструменты |
|---|--------|--------|----------------------|
| 1 | [A/B-тестирование: Яндекс Книги и интернет-магазин](01-ab-testing/) | Проверить гипотезу об активности пользователей двух городов и оценить, повышает ли новый интерфейс конверсию в покупку | t-тест Уэлча, Z-тест пропорций, расчёт размера выборки (power analysis), проверка корректности теста |
| 2 | [Яндекс Афиша: поведение пользователей и сезонность спроса](02-yandex-afisha/) | Найти изменения в спросе на билеты осенью, ключевые регионы и партнёров, различия между mobile и desktop | EDA, сегментация, анализ динамики DAU и заказов, критерий Манна — Уитни |
| 3 | [Рынок стартапов: динамика и структура финансирования](03-startup-investments/) | Понять, как менялось финансирование стартапов, и дать рекомендацию инвестору | Предобработка «грязных» данных, feature engineering, выбросы по IQR, анализ временных рядов |

## Стек

- **Python:** pandas, numpy, matplotlib, seaborn, scipy, statsmodels
- **SQL:** выгрузка и предобработка данных
- **Статистика:** A/B-тесты, t-тест Уэлча, Z-тест пропорций, критерий Манна — Уитни, расчёт мощности и MDE
- **Продуктовые метрики:** конверсия, DAU, средний чек, сегментация пользователей
