# Яндекс Афиша: поведение пользователей и сезонность спроса

📓 Ноутбук: [yandex_afisha_eda.ipynb](yandex_afisha_eda.ipynb)

**Задача:** провести исследовательский анализ заказов билетов в Яндекс Афише: понять, как меняется спрос осенью по сравнению с летом, какие регионы и партнёры дают основной вклад, и различается ли поведение пользователей мобильного приложения и десктопа.

**Данные:** ~290 тыс. заказов билетов за 2024 год, справочник из ~22 тыс. мероприятий и курс тенге к рублю (для пересчёта выручки в единую валюту).

## Что сделала

- **Предобработка:** привела типы дат, пересчитала выручку из тенге в рубли по дневному курсу, удалила неявные дубликаты, отсекла выбросы выручки выше 99-го перцентиля, объединила три источника в единый датасет.
- **Сегментация и сезонность:** сравнила структуру заказов летом и осенью по типам мероприятий, устройствам и возрастным категориям; рассчитала среднюю выручку с билета по сегментам.
- **Динамика активности:** посчитала ежедневное число заказов, активных пользователей (DAU) и среднюю цену билета; проанализировала недельную цикличность.
- **Регионы и партнёры:** доли мероприятий, заказов и выручки по регионам и билетным операторам.
- **Статистика:** проверила две гипотезы о различиях mobile vs desktop с помощью критерия Манна — Уитни (распределения ненормальные).

## Ключевые выводы

- С конца лета число заказов растёт; осенью растёт доля спорта и театра, а доля концертов снижается.
- Пик осенних заказов (30 сентября) совпал с минимальной ценой билета: высокий спрос не означает высокий средний чек.
- В будни заказов и активных пользователей больше, но средняя цена билета выше в выходные.
- Два крупнейших региона дают около 41% мероприятий; один регион — почти 28% всех заказов. Среди партнёров явного лидера нет: число мероприятий не всегда пропорционально заказам и выручке.
- Пользователи мобильного приложения делают значимо больше заказов на человека (p < 0.001); различий во времени между заказами не обнаружено (p = 0.79).

## Рекомендации

1. Учитывать сезонность и расширять осенью предложение в растущих категориях.
2. Развивать мобильный канал — именно там самые активные покупатели.
3. Оценивать партнёров по комплексу метрик (мероприятия, заказы, выручка), а не по одному показателю.
4. Регулярно мониторить средний чек по категориям для корректировки ценовой политики.
